# Enrollment controls

Grace Wilson reviews the dated waitlist in request order within each club. Robotics has one unallocated place held for room supervision review. Ceramics has one held for equipment review. These places count toward room capacity but are not available to promise. An absent attendee is still enrolled. Release a place only after a withdrawal or an explicit owner decision; never treat one missed session as a vacancy. Public reports contain club totals and anonymous request IDs only.
