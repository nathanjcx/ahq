Platform admin

Unchanged in function: drafts, versions, provider OAuth clients, the reviewed tool registry. Only platform admins see this destination.

Information architecture

Fifteen destinations become six, plus Settings and Platform admin. Every existing feature keeps a home; nothing is dropped.

  • Work (default). The inbox of everything in motion, grouped by what it needs from you. One row per thread: a task, an approval, a question, a handoff, an incident, a report. Actions inline (answer, approve, add context, reassign). The right pane is the thread. Replaces Tasks, Inbox, the review bar, and most of Triage.
  • Office. The 3D room, one floor at a time, with a rail for the floor's people, week, and board. Replaces Office page and the floor tabs.
  • Team. Employees (table + detail), Hire (marketplace), Floors (staffing). Replaces Employees, Marketplace, floor editing.
  • Plan. Projects, Calendar, Meetings. Replaces Projects and Calendar.
  • Records. Files, Activity, Memory, Audit. Replaces Files, Activity, Records, Audit.
  • Integrations. Unchanged, denser.
  • Settings and Platform admin move to the bottom of the sidebar.

Shell rules

  • One 48px header per page: title, tabs, search, primary action. No page intros, no eyebrows, no nested card headers.
  • Lists are tables or streams with a fixed right detail pane, not stacked cards.
  • Status is a small tag with four tones: needs you, working, waiting, incident.
  • Type: 13px base, 15px titles. One accent. No gradients.

Work, in detail

  • Grouped by Needs you · Running · Waiting on others · Done today; filters by employee and floor.
  • A question from an employee renders as options you tap; an approval renders as a preview with Approve / Edit / Reject.
  • The composer adds context (files, links, Drive), mentions people, and can save a line as memory so it holds for future shifts.
  • Everything here is live from Convex; the row updates as the employee works.
